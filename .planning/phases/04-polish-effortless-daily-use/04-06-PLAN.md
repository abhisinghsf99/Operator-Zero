| Boundary | Description |
|----------|-------------|
| mobile client → surfaces | mobile must not gain or lose authorization vs desktop (real parity, not a separate weaker path) |
| keyboard handler → actions | global keydown must not trigger destructive actions while typing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-06-01 | Tampering | keyboard shortcut fires action while typing | mitigate | handler skips INPUT/TEXTAREA/contenteditable + scoped to data-approval-detail (Pitfall 5) |
| T-4-06-02 | Elevation of Privilege | mobile path bypassing a desktop authz/ownership check | mitigate | mobile reuses the SAME Server Actions (ownership re-checks intact); no mobile-only endpoints |
| T-4-06-03 | Information Disclosure | cached surface data leaking across users | mitigate | unstable_cache keys/tags are per-user (revalidateTag scoped by userId); RLS still enforced on reads |
