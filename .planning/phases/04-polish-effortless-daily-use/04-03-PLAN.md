<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Server Action | brand voice / memory / profile inputs are untrusted; cross-tenant write risk |
| DB at rest | brand voice markdown is sensitive content requiring encryption at rest |
| model output → preview | regenerated draft + markdown preview must not enable XSS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-03-01 | Information Disclosure | brand_voice_profiles at rest | mitigate | encryptToken (libsodium via crypto.ts) before write; read path try-catch decrypt (legacy plaintext tolerance, A2) |
| T-4-03-02 | Tampering | saveBrandVoice/memory/profile cross-tenant | mitigate | getValidatedClaims; userId from claims.sub only; serviceDb writes filter by user_id; RLS on tables |
| T-4-03-03 | Tampering | XSS via markdown preview / regenerated draft | mitigate | react-markdown WITHOUT rehype-raw (no raw HTML passthrough) per [02-06] convention |
| T-4-03-04 | Spoofing | silent overwrite of brand voice on regenerate | mitigate | regenerateBrandVoice returns draft only; explicit Save required (SET-02, no silent overwrite) |
| T-4-03-05 | Tampering | memory category injection | mitigate | category restricted to the allowed enum in Zod before storeMemoryItem |
</threat_model>
