| model output → markdown preview | content draft markdown could carry XSS |
| user → chat send volume | repeated sends are a cost/DoS surface |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-2-06-02 | Tampering | XSS via content-preview markdown | mitigate | react-markdown sanitizing renderer; no raw HTML injection (RESEARCH Don't-Hand-Roll) |
| T-2-06-03 | Denial of Service | chat send flooding | mitigate | chatRateLimit.limit(userId) → 429 before any LLM call (AUTH-06) + cost cap (AUTH-07) |

| T-2-06-05 | Information Disclosure | Realtime cross-user leakage | mitigate | Supabase Realtime channels set { private:true } with the user JWT (Pitfall 5) |
