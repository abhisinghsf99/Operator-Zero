<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → OAuth connect/callback | state + shop are user-controlled; CSRF/open-redirect surface |
| Shopify → webhook receiver | webhook payloads are untrusted until HMAC-verified |
| stored token → Shopify Admin API | token must remain encrypted at rest |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-03-01 | Spoofing | OAuth callback state | mitigate | Cryptographic nonce stored per-user, compared in callback; 400 on mismatch |
| T-2-03-02 | Tampering | OAuth callback HMAC | mitigate | HMAC-SHA256 verified via @shopify/shopify-api before any DB write; 400 on mismatch |
| T-2-03-03 | Elevation | shop param SSRF/open-redirect | mitigate | shop validated against /^[a-z0-9-]+\.myshopify\.com$/ before use in any URL |
| T-2-03-04 | Spoofing/Tampering | webhook forgery/replay | mitigate | X-Shopify-Hmac-Sha256 verified (timing-safe) before processing; 401 on failure |
| T-2-03-05 | Information Disclosure | stored Shopify token | mitigate | encryptToken (libsodium) at rest; decrypt only in agent/server tier; never logged |
| T-2-03-06 | Tampering | duplicate write on retry | mitigate | idempotency key on writes + re-read mirror; INTEG-07 |
</threat_model>
