<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → onboarding step params | step / skipGmail are user-controlled |
| onboarding → /onboarding route | must be reachable pre-completion but still authenticated |
| settings → disconnect | destructive (deletes integration + mirror) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-08-01 | Elevation | unauthenticated /onboarding access | mitigate | middleware redirects unauthenticated /onboarding to /login; completed users cannot re-enter |
| T-2-08-02 | Tampering | forged onboarding_step / skipGmail | mitigate | Zod-validate step inputs; user_id from getClaims (never client-supplied); Shopify gate checks the real integrations row, not a client flag |
| T-2-08-03 | Tampering | prompt injection via product data in catalog audit | mitigate | Audit is read-only; product fields summarized as data; suggestions parsed as structured JSON, not executed |
| T-2-08-04 | Information Disclosure | cross-user integration display in Settings | mitigate | Settings reads via withUserRls; disconnect re-checks ownership |
| T-2-08-05 | Tampering | accidental/forced disconnect | mitigate | Disconnect requires a confirm dialog + ownership check before deleting integration + mirror |
</threat_model>
