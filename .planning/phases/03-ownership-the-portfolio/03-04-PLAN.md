<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Server Action | activityId / activityIds[] / cursor / filters arrive from the browser |
| activity_entries JSONB → diff renderer | before_state/after_state may contain arbitrary strings |
| npm registry → build | @tanstack/react-virtual install |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-04-01 | Spoofing/Elevation | revertActivity / bulkRevertActivity | mitigate | Server Actions (plan 01) filter activity_entries WHERE user_id = userId; cross-user IDs silently excluded |
| T-3-04-02 | Tampering | canRevert bypass via direct Server Action call | mitigate | Server Action re-evaluates canRevert independently (re-fetches shopify_updated_at) — UI canRevert is convenience only |
| T-3-04-03 | Information Disclosure | client cursor used for pagination | mitigate | fetchActivityPage re-filters by user_id regardless of cursor — cursor cannot read another user's rows |
| T-3-04-04 | Tampering (XSS) | before/after JSONB rendered in diff | mitigate | renderFieldDiff treats all field values as data; React auto-escapes; never dangerouslySetInnerHTML |
| T-3-04-SC | Tampering | npm install @tanstack/react-virtual | mitigate | [ASSUMED] package — Task 1 blocking-human checkpoint verifies official TanStack package on npmjs.com before install |
</threat_model>
