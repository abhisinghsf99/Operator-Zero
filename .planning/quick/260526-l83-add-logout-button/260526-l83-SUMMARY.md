## What Was Built

**Task 1 — LogOut icon (`components/design/icons.tsx`)**
Added `LogOut` entry to the `Icons` object following the exact format of existing entries. Uses the standard lucide-style logout glyph:
- `<path d="M9 21H5a2 2 0 0 1-2-2V5a2 2 0 0 1 2-2h4" />` (door frame)
- `<path d="M16 17l5-5-5-5M21 12H9" />` (arrow pointing out)

`IconName` type auto-derives `"LogOut"` from the new key — no manual type edit needed.

**Task 2 — Sidebar footer sign-out row (`components/layout/sidebar.tsx`)**
- Imported `signOut` from `@/app/app/actions`
- Added `<form action={signOut}>` wrapping a `<button type="submit">` inserted after the Settings `<Link>` and before the account-card `<Link>`
- Button styled with identical nav-link className pattern as the Settings inactive state (same flex/padding/rounded/text/transition/focus-ring/hover/motion-reduce classes), plus `w-full text-left`
- Renders `<Icons.LogOut size={15} strokeWidth={1.5} />` + "Sign out" label
- `aria-label="Sign out of this device"` for WCAG AA compliance
- No confirm dialog (low-risk, reversible)

**Task 3 — Sessions page sign-out button (`app/app/settings/_sessions.tsx`)**
- Imported `signOut` from `@/app/app/actions`
- Added `<form action={signOut} style={{ marginBottom: 10 }}>` wrapping `<Button variant="secondary" size="md" icon="LogOut" type="submit" aria-label="Sign out of this device">Sign out</Button>`
- Placed inside the existing `<div style={{ marginTop: 14 }}>` container, above the "Sign out everywhere" danger button
- "Sign out everywhere" button, `signOutOpen`/`handleSignOutEverywhere` logic, and confirm Dialog all unchanged
